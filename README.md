# Road-Accident-Analysis
An Excel-based Road Accident Analysis project where I analyzed casualty trends, severity, vehicle types, road conditions, and urban vs. rural areas. I used Pivot Tables, charts, KPIs, and an interactive dashboard to turn raw accident data into useful insights.
# 🚗 Road Accident Analysis

## 📌 Project Overview

This project is an Excel-based Road Accident Analysis created to explore and analyze road accident data.

The project focuses on analyzing casualties based on accident severity, vehicle type, road type, road surface, urban/rural areas, light conditions, and time-based trends.

The raw data was analyzed using Microsoft Excel, with Pivot Tables, charts, KPIs, and an interactive dashboard used to present the analysis in a simple and understandable way.

---

## 🎯 Project Objectives

- Analyze road accident data using Microsoft Excel
- Understand accident casualty patterns
- Analyze accident severity
- Identify yearly and monthly trends
- Analyze casualties by vehicle type
- Compare urban and rural areas
- Analyze different road types and road surface conditions
- Analyze casualties under different light conditions
- Create KPIs for quick analysis
- Build an interactive Excel dashboard
- Present the analysis through clear visualizations
